    "Build Update UF2" re-reads the device's current sample list, then downloads a UF2 containing
    just the new samples plus an updated index (minus anything marked for deletion above) — flash
    it via BOOTSEL drag-and-drop or picotool, same as any other UF2. Samples aren't resampled; the
    device honours each sample's original rate. "Export Library" saves everything staged here (not
    yet flashed) to a single file you can re-import later or share with someone else so they get
    the same samples.
  


  
Rebuild from library (reclaim flash space)

  

    Deleting samples above only removes them from the index — their audio bytes stay in flash
    until a full rebuild. This discards the device's entire current sample store and
    replaces it with only what's staged below (import a previously-exported library first if
    needed), reclaiming all deleted/orphaned space.
